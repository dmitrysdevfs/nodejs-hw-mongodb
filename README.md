# Node.JS 2.0 HW-MongoDB

This repository contains a **series of homework assignments** for the **Node.JS 2.0** course in the **FSON-112** group.
The main goal of this project is to **develop a backend for a phonebook application**.

It is built using **Express.js** and works with **MongoDB Atlas** as the database.
The project is deployed on **Render**.

Each assignment is completed in a **separate branch**, ensuring structured organization and easy navigation.

## Repository Structure

- **Main branch** contains the base setup for all assignments.
- **Each homework task** is developed in its own branch.

## Technologies Used

- **Node.js** – runtime environment
- **Express.js** – web framework
- **MongoDB Atlas** – cloud database
- **Render** – deployment platform
- **ESLint** – code linting
- **Nodemon** – development utility
